# Шаблон интернет-магазина

Node.js + Express + встроенный SQLite (`node:sqlite`) + Stripe. Витрина — SPA на чистом JS, без сборки.

## Запуск

```bash
npm install
cp .env.example .env   # при желании поправьте
npm start              # http://localhost:3000
```

Нужен Node.js ≥ 22.5. База (`data/shop.db`) и демо-товары создаются автоматически.
Админ по умолчанию: `admin@shop.local` / `admin12345` — **смените в `.env` до первого запуска**.

## Возможности

**Покупатель:** каталог, поиск, категории, фильтр по цене/наличию, сортировка, пагинация, страница товара,
отзывы и рейтинг, избранное, корзина (localStorage), промокоды, способы доставки (бесплатно от суммы),
гостевой заказ или с аккаунтом, история заказов, регистрация/вход.

**Оплата:** Stripe Checkout (карты, Apple/Google Pay — по настройкам Stripe). Без ключа работает
демо-оплата (карта `4242 4242 4242 4242`).

**Админка** (`#/admin`): сводка и выручка, заказы со сменой статуса (отмена возвращает товар на склад),
CRUD товаров, категории, промокоды, остатки.

**Безопасность:** цены и скидки считаются только на сервере, пароли — scrypt, сессии в httpOnly-cookie,
экранирование HTML, ограничение попыток входа, проверка подписи вебхука Stripe, склад списывается при оплате.

## Подключение Stripe

1. В `.env`: `STRIPE_SECRET_KEY=sk_test_...`, `CURRENCY=rub` (или `usd`/`eur`).
2. Вебхук (рекомендуется): `stripe listen --forward-to localhost:3000/api/stripe/webhook`
   и значение `whsec_...` в `STRIPE_WEBHOOK_SECRET`. Без вебхука оплата подтверждается при возврате на сайт.
3. Для продакшена задайте `BASE_URL=https://ваш-домен` (по https cookie становится Secure).

## Что доработать под проект

- Отправка писем: заглушка `notify()` в `server.js` — подключите nodemailer/Resend.
- Загрузка фото: сейчас товар хранит URL картинки.
- Для нескольких серверов/высокой нагрузки — замените SQLite на PostgreSQL.
- Реальные ЮKassa/CloudPayments и т.п. — добавьте по образцу `/api/checkout` (создание платежа) + вебхук → `markPaid()`.
